# Demonstration assets

`assets/` contains four anonymised, generated demonstration images for local UI
and workflow validation. They do not represent a real project, camera or safety
finding. They contain no EXIF metadata, people, site names, vehicle plates or
camera credentials.

The files are intentionally not training data and must not be used to claim model
accuracy. For a real evaluation, provide authorised private test images together
with label definitions and ground-truth records.
